# Kendall’s Tau-b Worked Resource

Kendall’s tau-b measures monotonic ordinal association while correcting for tied ranks in both variables.

The tie-corrected coefficient is `τb = (C − D) / √[(C + D + Tₓ)(C + D + Tᵧ)]`, where `C` and `D` are concordant and discordant pairs.
