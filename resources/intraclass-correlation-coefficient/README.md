# Intraclass Correlation Coefficient Worked Resource

The intraclass correlation coefficient estimates reliability or agreement among repeated ratings, raters, measurements, or time points.

Model selection should answer four questions: one-way or two-way, random or mixed, single or average measurement, and consistency or absolute agreement.
