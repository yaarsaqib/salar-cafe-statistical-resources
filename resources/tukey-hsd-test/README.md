# Tukey HSD Test Worked Resource

Tukey’s honestly significant difference test identifies which group means differ after an ANOVA while controlling the familywise error rate.

For a balanced design, the core comparison uses `HSD = q-critical × √(MSE / n)`. Interpretation should focus on adjusted pairwise differences and simultaneous confidence intervals.
