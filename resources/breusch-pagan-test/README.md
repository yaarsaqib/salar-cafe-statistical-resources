# Breusch–Pagan Test Worked Resource

The Breusch–Pagan test evaluates whether regression residual variance changes systematically across predictors or fitted values. A common implementation regresses squared residuals on explanatory variables and uses `LM = n × R²` as the test statistic.

## Practical interpretation

A small p-value suggests heteroscedasticity. It does not automatically invalidate the regression or justify deleting observations. Investigate residual plots, model form, omitted variables, scale choices, and robust standard errors.
