# Dice Counter Practice Resource

The Dice Counter records dice outcomes, roll histories, face frequencies, totals, and percentages for games, probability lessons, and classroom experiments.

A simple frequency percentage is calculated as `face count ÷ total rolls × 100`.

[Open the free online Dice Counter](https://onlineinternetcafe.com/dice-counter/)

This resource is useful for probability demonstrations, expected-versus-observed comparisons, board-game sessions, and teaching relative frequency.
