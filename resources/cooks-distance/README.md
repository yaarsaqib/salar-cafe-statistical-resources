# Cook’s Distance Worked Resource

Cook’s distance identifies observations that may materially influence a fitted regression model because of large residuals, high leverage, or both.

A large Cook’s D value is a diagnostic signal, not an automatic delete rule. Investigate data accuracy, model specification, leverage, residual size, and sensitivity to case removal.

[Open the complete Cook’s distance guide](https://onlineinternetcafe.com/cooks-distance/)

The full guide includes the formula, leverage, studentized residuals, influence plots, threshold rules, interpretation, and SPSS, Python, R, and Excel workflows.
