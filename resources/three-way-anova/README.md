# Three-Way ANOVA Worked Resource

Three-way ANOVA tests three categorical factors, all two-way interactions, and the three-way interaction for one continuous outcome.

The model can be summarized as `Y = μ + A + B + C + AB + AC + BC + ABC + ε`.

[Open the complete three-way ANOVA guide](https://onlineinternetcafe.com/three-way-anova/)

The full resource covers main effects, interactions, simple effects, plots, assumptions, reporting, and SPSS, Python, R, and Excel workflows.
