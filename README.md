# Salar Cafe Statistical Learning Resources

Open, practical resources for statistics, reliability analysis, regression diagnostics, ANOVA, multivariate analysis, correlation, and probability education.

Each topic folder contains an original method overview and a synthetic practice dataset. The complete guides provide formulas, assumptions, interpretation, worked examples, charts, reporting guidance, and workflows for SPSS, Python, R, and Excel.

## Intended use

These materials are suitable for students, teachers, analysts, researchers, and software learners. The datasets are synthetic and intended for teaching and reproducibility practice rather than substantive research conclusions.
